# HDR Dynamic Up-Mapping (PQ)
A dynamic up-mapping shader for PQ-encoded HDR signals.

- `hdr_dynamic_up_mapping_pq.fx` — English version.
Download the `.fx` file and place it in your ReShade shader folder:
`\reshade-shaders\Shaders`
Launch your game or play a video in mpv, open the ReShade menu, and enable **HDR Dynamic Up-Mapping (PQ)**.

- `hdr_dynamic_up_mapping_pq_cn.fx` — 中文版。
下载后放入 ReShade 着色器文件夹：
`\reshade-shaders\Shaders`
启动游戏或使用 MPV 播放视频，唤出 ReShade 菜单，勾选 **HDR 向上动态映射**。
